# Доски

При экспорте из Trello доски преобразуются в очереди Yandex Tracker с сохранением основной информации и структуры.

## Соответствие полей

| Trello                 | Yandex Tracker         |
|------------------------|------------------------|
| Доска                  | Очередь                |
| Кастомные поля         | Локальные поля очереди |
| Колонки                | Статусы                |


## Автоматически генерируемые поля

- **Рабочий процесс**: Создается на основе колонок в доске. Рабочий процесс очереди строится по принципу "Из любого статуса в любой"
- **Стандартный тип задачи при создании**: `task` (задача)
- **Стандартный приоритет задачи**: `normal` (средний)

## Особенности экспорта

1. ⚠️ **Важно**: При экспорте отдельной доски автоматически экспортируется все карточки, которые к ней привязаны. Доска преобразуется в очередь Yandex Tracker.

2. Ответственным в очереди устанавливается создатель доски в Trello, а если он неизвестен — владелец токена.

3. Каталог `data/projects/`, оставшийся от выгрузки прежней версией, удалите до импорта.
