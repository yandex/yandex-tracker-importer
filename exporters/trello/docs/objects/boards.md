# Доски

При экспорте из Trello доски преобразуются в очереди и проекты Yandex Tracker с сохранением основной информации и структуры.

## Соответствие полей

| Trello                 | Yandex Tracker         |
|------------------------|------------------------|
| Доска                  | Очередь, проект        |
| Кастомные поля         | Локальные поля очереди |
| Колонки                | Статусы                |


## Автоматически генерируемые поля

- **Рабочий процесс (только для очередей)**: Создается на основе колонок в доске. Рабочий процесс очереди строится по принципу "Из любого статуса в любой"
- **Стандартный тип задачи при создании (только для очередей)**: `task` (задача)
- **Стандартный приоритет задачи (только для очередей)**: `normal` (средний)
- **Настройки доступа (только для проектов)**: `true` (доступ только для участников проекта)

## Особенности экспорта

1. ⚠️ **Важно**: При экспорте отдельной доски автоматически экспортируется все карточки, которые к ней привязаны. Доска преобразуется в очередь и проект Yandex Tracker.

2. Ответственным в очереди и создателем в проекте устанавливается создатель доски в Trello.

3. Все карточки, находящиеся на доске автоматически привязываются к проекту
