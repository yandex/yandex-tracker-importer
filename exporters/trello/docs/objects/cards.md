# Карточки

При экспорте из Trello карточки преобразуются в задачи Yandex Tracker с сохранением основной информации и структуры.

## Соответствие полей

| Trello      | Yandex Tracker |
|-------------|----------------|
| Карточка    | Задача         |
| Метки       | Теги           |
| Чеклисты    | Чеклист        |
| Вложения    | Вложения       |
| Комментарии | Комментарии    |
| Колонка     | Статус         |


## Автоматически генерируемые поля

- **Ключ задачи**: формируется автоматически (`QUEUEKEY-1`, `QUEUEKEY-2`, ...)
- **Тип задачи**: `task` (задача) для всех карточек
- **Приоритет**: `normal` (средний) для всех карточек

## Особенности экспорта

1. Вложения, которые не являются скачиваемыми файлами переносятся в описание задачи.

2. Имена вложений автоматически преобразуются для уникальности:
   - Исходное имя: `document.pdf`
   - Преобразованное имя: `document_123.pdf` (где 123 - ID вложения).

3. Все чеклисты при экспорте объединяются в один чеклист в рамках одной карточки.

4. Локальное поле `Checkbox` преобразуется в текстовое поле с выбором значения между `Да` и `Нет`.
