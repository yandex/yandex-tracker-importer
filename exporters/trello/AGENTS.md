# AGENTS.md — руководство для ИИ-агента: миграция Trello → Yandex Tracker

Ты помогаешь пользователю перенести доски **Trello** в **Yandex Tracker**. Этот
инструмент выгружает доски и карточки Trello в YAML, совместимый с универсальным
импортером в Yandex Tracker (`trackin`). Полный конвейер:

```
Trello API  →  trello exporter (этот проект)  →  data/*.yaml  →  trackin  →  Yandex Tracker
```

Экспортер **только читает** Trello и пишет файлы — ничего в Trello и Трекере не меняет.
Заливкой в Трекер занимается отдельный импортёр `trackin`.

---

## Что спросить у пользователя

1. **API key Trello** — см. «Получение доступов».
2. **OAuth token Trello** — там же.
3. **Какие доски переносить** — можешь помочь выбрать (см. «Шаг 1»).
4. **Ключи очередей** в Трекере для каждой доски — короткие, латиницей (`PROD`).
   Можешь предложить сам из названий досок.

> Токен — секрет: не выводи в логи, не коммить, предложи перевыпустить после миграции.

## Получение доступов

1. **API key:** открой <https://trello.com/app-key>, скопируй значение **Key** в
   `configs/source_trello_api.cfg`.
2. **OAuth token:** на той же странице нажми **Token** (или открой
   `https://trello.com/1/authorize?expiration=never&name=TrelloExporter&scope=read&response_type=token&key=<API_KEY>`),
   подтверди доступ, скопируй токен в `configs/source_trello_token.cfg`.

Экспортеру достаточно прав `read`. Токен удобно выпускать с `expiration=never`.

## Шаг 1. Discovery — помоги выбрать доски

Список досок пользователя:

```bash
curl "https://api.trello.com/1/members/me/boards?fields=name&key=<API_KEY>&token=<TOKEN>"
```

Каждая доска — `id` + `name`. Предложи пользователю строки `<board_id>:<QUEUE_KEY>`
(ключ — короткий латиницей из названия доски).

## Шаг 2. Собери образ

```bash
docker build -t trello-exporter:latest .    # либо podman build …
```

## Шаг 3. Подготовь `configs/` и запусти

```
configs/
├── source_trello_api.cfg     # API key
├── source_trello_token.cfg   # OAuth token
└── boards.cfg                # <board_id>:<QUEUE_KEY>, по строке на доску
```

```bash
docker run --rm -v "$(pwd)":/work -w /work trello-exporter:latest
```

Флаги передаются после имени образа, напр. `--workers <N>` (число потоков).
**Совет:** начни с ОДНОЙ доски, проверь результат, потом добавь остальные в
`boards.cfg`. Результат — в `data/`, логи — в `logs/`.

## Шаг 4. Проверь выгрузку

- `data/queues/<KEY>/queue.yaml` — очередь, статусы, воркфлоу, локальные поля;
- `data/queues/<KEY>/<KEY>-N/issue.yaml` — задачи (рядом `attachments/`);
- `data/{statuses,categories}.yaml` — общие справочники.

Открой пару `issue.yaml` и убедись, что `summary`/`status`/`tags`/`comments`
выглядят осмысленно.

## Шаг 5. Импорт в Tracker (через `trackin`)

Готовые `data/` заливает импортёр `trackin`. Ключевой ручной шаг —
**сопоставление пользователей**: Trello отдаёт людей по **полному имени**
(`fullName`), при импорте их надо смапить на логины Трекера в `mapping/users.cfg`.

---

## Карта соответствий

| Trello | Yandex Tracker |
|---|---|
| Доска (board) | Очередь + Проект |
| Колонка (list) | Статус |
| Карточка (card) | Задача |
| Метки (labels) | Теги |
| Чек-листы | Чек-лист (все объединяются в один) |
| Вложения / комментарии | одноимённое |
| Кастомные поля (list/number/checkbox/date/text) | Локальные поля очереди |

Тип задачи и приоритет у всех карточек — `task` / `normal`. Ключи задач —
`<QUEUE_KEY>-N` по порядку создания. Подробности — в [`README.md`](README.md) и
[`docs/`](docs/).

## Ограничения (проговори пользователю заранее)

- **Пользователи** переносятся по полному имени (`fullName`) и требуют ручного
  маппинга на логины Трекера (`mapping/users.cfg`).
- **Нескачиваемые вложения** (ссылки, а не файлы) переносятся в описание задачи,
  а не в `attachments`.
- Все **чек-листы** карточки объединяются в один.
- Даты/автор создания задачи проставляются на шаге импорта, а не экспортёром.

## Безопасность

- Не выполняй разрушительных операций; экспортер работает только на чтение Trello.
- Всегда проверяй результат на одной доске до массового прогона.
- Токены не сохраняй в репозиторий; предложи перевыпустить их после миграции.
