# Скрам

Для скрам-группы выгружаются доска со спринтами и эпики. Доски выгружаются только для скрам-групп.

## Доска

Доска скрам-группы попадает в `boards.yaml`.

| Bitrix24                 | Yandex Tracker                                                        |
|--------------------------|-----------------------------------------------------------------------|
| Скрам-группа             | Доска `bitrix24-<id группы>` с названием группы, со спринтами и бэклогом, оценка — `storyPoints` |
| Владелец группы          | `createdBy` доски                                                     |
| Состав доски             | Правило добавления: задачи типа `task` проекта группы                 |
| Колонки                  | По одной на статус из [описания задач](./issues.md#статусы-и-резолюции) |
| Спринт                   | Спринт `bitrix24-sprint-<id спринта>` с названием и датами начала и окончания |

| Статус спринта Bitrix24 | Статус спринта Трекера |
|-------------------------|------------------------|
| Запланирован            | `draft`                |
| Активный                | `in_progress`          |
| Завершён                | `released`             |

Задача спринта ссылается на доску и спринт, задача бэклога — только на доску. Стадия задачи на доске спринта
выгружается в поле `kanbanStatus`. Задача группы, которой нет в бэклоге и спринтах (например, подзадача), выгружается
без доски, спринта, story points и связи с эпиком.

Ссылка задачи на спринт или эпик, которого Bitrix24 не вернул, не выгружается; в журнале — предупреждение, для
спринта — если Bitrix24 вернул бэклог группы.

## Эпики

Эпики скрам-групп выгружаются задачами типа `epic` в очередь `EPIC` с ключом `EPIC-<id эпика>`; задача скрам-группы
связана со своим эпиком связью `has epic`. Эпики группы выгружаются вместе с первой выгружаемой задачей группы. Если
эпики группы не выгрузились, задачи группы с эпиком не выгружаются, экспорт завершается с кодом 1.

| Bitrix24              | Yandex Tracker                                   |
|-----------------------|--------------------------------------------------|
| Название              | `summary`                                        |
| Описание              | `description`: абзацы, переносы строк, списки, выделение и ссылки |
| Файлы                 | Вложения                                         |
| Автор                 | `createdBy`                                      |
| Автор изменения       | `updatedBy`, без значения — автор эпика          |
| Группа                | Проект                                           |

Дата создания эпика — дата создания группы: Bitrix24 не отдаёт даты эпика. Дата изменения — самая поздняя из даты
создания и дат его файлов. Статус эпика — `open`.

Очередь `EPIC` получает тип задач по умолчанию `epic` и тот же рабочий процесс, что очереди потоков.
