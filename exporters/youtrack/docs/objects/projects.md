# Проекты, статусы, поля и доски

## Проект

Проект YouTrack становится очередью Трекера. Ключ очереди задаётся в `configs/projects.cfg`.

| YouTrack              | Yandex Tracker                                   |
|-----------------------|--------------------------------------------------|
| Название              | Название очереди                                 |
| Описание              | Описание очереди                                 |
| Руководитель          | Владелец очереди                                 |
| Команда               | Участники очереди                                |
| Роли в проекте        | Права очереди                                    |
| Значения поля статусов (State) | Статусы рабочего процесса очереди       |
| Значения поля Type    | Типы задач очереди                               |
| Значения Subsystem («Подсистема») | Компоненты очереди, владелец — владелец значения |
| Версии                | Версии очереди                                   |
| Остальные поля        | Локальные поля очереди                           |

Архивный проект не выгружается: восстановите его из архива перед экспортом.

### Доступ

Права очереди строятся по ролям YouTrack в проекте и глобальным ролям:

| Право роли YouTrack | Право очереди          |
|---------------------|------------------------|
| Read Issue          | Чтение (`read`)        |
| Create Issue        | Создание (`create`)    |
| Update Issue        | Изменение (`write`)    |

Кто получает право:

- пользователь с ролью — по e-mail;
- команда проекта с ролью — её участники по e-mail и её группы по названию;
- группа с ролью — по названию;
- группы «All Users» и «Registered Users» — группа «Все сотрудники».

Если «All Users» или «Registered Users» читают, создают и изменяют задачи проекта, права очереди не
задаются: доступ к ней такой же, как к новой очереди Трекера.

Если права не получает никто из выгрузки, они остаются только у владельца токена.

Если YouTrack не отдаёт роли, команда проекта получает чтение, создание и изменение задач.

Группа ищется в Трекере по названию. Если она называется иначе, сопоставьте её в `mapping/groups.cfg`
импортера.

## Статусы и резолюции

Поле статусов — поле State типа «состояние»; если его нет — первое поле типа «состояние» проекта. Остальные
поля типа «состояние» становятся локальными полями.

Каждое значение поля статусов становится статусом:

| Значение поля статусов                        | Тип статуса         |
|-----------------------------------------------|---------------------|
| Первое нерешённое                             | Начальный (`new`)   |
| Остальные нерешённые                          | В работе (`inProgress`) |
| Решённое с резолюцией «Решен»                 | Завершён (`done`)   |
| Решённое с другой резолюцией                  | Отменён (`cancelled`) |

Резолюция решённого значения:

| Значение поля статусов | Резолюция                |
|--------------------|------------------------------|
| Duplicate          | Дубликат (`duplicate`)       |
| Won't fix          | Не будет исправлено (`wontFix`) |
| Can't Reproduce    | Не воспроизводится (`cantReproduce`) |
| Obsolete, Incomplete | Не делаем (`dontDo`)       |
| Остальные          | Решен (`fixed`)              |

- У встроенных значений YouTrack два названия: английское и на языке YouTrack. Они становятся английским
  и русским названием статуса. У значений, созданных пользователем, одно название — на обоих языках.
- Значения с одинаковым английским названием во всех проектах — один статус; его тип определяет первый
  проект из `projects.cfg`.
- Если названия разных статусов совпадают, к названию добавляется « (2)», « (3)».

Рабочий процесс очереди разрешает переход из любого статуса в любой.

## Типы задач и приоритеты

| Type в YouTrack | Тип задачи                     |
|-----------------|--------------------------------|
| Bug             | Ошибка (`bug`)                 |
| Task            | Задача (`task`)                |
| Feature         | Новая возможность (`newFeature`) |
| Epic            | `epic`                         |
| User Story      | `story`                        |
| Остальные       | Новый тип с тем же названием   |

Тип задачи по умолчанию — `task`, если он есть в проекте, иначе первый тип проекта.

| Priority в YouTrack | Приоритет           |
|---------------------|---------------------|
| Show-stopper        | Блокер (`blocker`)  |
| Critical            | Критичный (`critical`) |
| Major, Normal       | Средний (`normal`)  |
| Minor               | Низкий (`minor`)    |
| Остальные           | Средний (`normal`)  |

## Поля

| Поле YouTrack                         | Поле задачи Трекера           |
|---------------------------------------|-------------------------------|
| Поле статусов (State)                 | `status`, `resolution`        |
| Type                                  | `type`                        |
| Priority                              | `priority`                    |
| Assignee                              | `assignee`                    |
| Subsystem                             | `components`                  |
| Fix versions                          | `fixVersions`                 |
| Affected versions                     | `affectedVersions`            |
| Due Date                              | `deadline`                    |
| Story points                          | `storyPoints`                 |
| Поле оценки учёта времени             | `originalEstimation`          |
| Поле затраченного времени             | `spent`                       |

Без поля Story points `storyPoints` берётся из числового поля, которым задачи оценивает доска проекта.

Не выгружаются как поля:

- поле спринтов доски проекта — задача попадает в спринт доски.

Остальные поля становятся локальными полями очереди:

| Тип поля YouTrack                              | Локальное поле Трекера             | Значение                 |
|------------------------------------------------|------------------------------------|--------------------------|
| `enum`, `state`, `ownedField`, `version`, `build`, `group` | Список строк с вариантами значений | Название значения |
| `user`                                         | Пользователь                       | E-mail                   |
| `integer`                                      | Целое число                        | Число                    |
| `float`                                        | Дробное число                      | Число                    |
| `string`                                       | Строка                             | Текст                    |
| `text`                                         | Многострочный текст                | Текст                    |
| `date`                                         | Дата                               | Дата                     |
| `date and time`                                | Дата/время                         | Дата и время             |
| `period`                                       | Целое число, описание «Минуты»     | Минуты                   |

Поле с выбором нескольких значений (`enum[*]`, `user[*]` и т. п.) становится полем-массивом.
Поля с одинаковым названием получают « (2)», « (3)».

## Доски и спринты

Agile-доска становится доской Трекера, если её колонки — значения поля статусов одного из её проектов из
выгрузки.

- **Колонки** по значениям поля статусов — колонки доски со статусами этих значений и ограничением
  числа задач.
- **Правило добавления** по очередям проектов доски — у доски без спринтов, которая сама добавляет новые
  задачи.
- **Оценка** — по `storyPoints`, если доска оценивает задачи полем Story points.
- **Спринты** с датами начала и конца переносятся с этими датами. Статус спринта:
  - архивный — `archived`;
  - закончился — `released`;
  - идёт — `in_progress`;
  - не начался — `draft`.

Задача попадает на доску, если она на доске в YouTrack.

- Задача в спринте с датами попадает в этот спринт.
- Задача в спринте без дат попадает на доску без спринта.
- Если задача в нескольких спринтах доски, в Трекере она в последнем из них.
