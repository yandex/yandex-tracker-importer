# Задачи

Задача YouTrack становится задачей очереди своего проекта. Ключ задачи — `<QUEUE_KEY>-<номер>`, номер
тот же, что в YouTrack. Черновики задач не выгружаются.

| YouTrack                          | Yandex Tracker                                   |
|-----------------------------------|--------------------------------------------------|
| Название                          | `summary`                                        |
| Описание                          | `description` в markdown                         |
| Автор, дата создания              | `createdBy`, `createdAt`                         |
| Кто и когда изменил               | `updatedBy`, `updatedAt`                         |
| Решённое состояние                | `status`, `resolution`, `resolvedAt`, `resolvedBy` |
| Системные поля (Priority, Assignee, Subsystem, версии, Due Date, Story points, учёт времени) | Поля Трекера — [таблица соответствия](./projects.md#поля) |
| Остальные поля проекта            | Локальные поля очереди — `local_<ключ>`          |
| Теги                              | `tags`                                           |
| Наблюдатели                       | `followers`                                      |
| Голоса                            | `votedBy`                                        |
| Доски, спринты                    | `boards`, `sprint`                               |
| Комментарии                       | `comments`                                       |
| Вложения                          | `attachments`                                    |
| Учёт времени                      | `worklogs`                                       |
| Связи                             | `links`                                          |
| Видимость                         | `components`, `access`                           |

- **Дата изменения** — самая поздняя из дат задачи, комментариев, вложений и связей.
- **Кто решил задачу** — автор последнего перехода в решённое состояние по истории задачи. Если его нет в
  истории — тот, кто последним изменил задачу.
- **Исполнители.** Если поле Assignee допускает несколько значений, первый становится исполнителем,
  остальные — наблюдателями.

## Видимость

Задача, видимая в YouTrack части пользователей, получает компонент «Ограниченная видимость» (название
задаётся в `configs/restricted_component.cfg`). Его права:
чтение и изменение — у автора, исполнителя, пользователей поля «Доступ» (`access`) и владельца очереди.
Если в проекте есть такие задачи, а среди значений поля Subsystem («Подсистема») есть значение с названием
компонента, проект не выгружается и попадает в сводку ошибок: задайте в файле другое название.

В поле «Доступ» записываются:

- пользователи из видимости задачи;
- участники групп из видимости задачи на момент экспорта.

Заблокированные пользователи и пользователи без e-mail в поле «Доступ» не попадают; пользователи без e-mail —
в сводке ошибок. Задача, видимая группе «All Users» или «Registered
Users», переносится без компонента.

Компонент появляется в очереди, если в проекте есть хотя бы одна такая задача.

Если участники группы из видимости задачи не загрузились, задача не выгружается и попадает в сводку ошибок.
Запустите экспорт ещё раз до импорта.

## Описание и комментарии

Текст переносится в markdown. Картинка или ссылка на вложение задачи (`![](схема.png)`, `[отчёт](отчёт.pdf)`)
становится ссылкой на перенесённое вложение.

Комментарий:

- автор и даты сохраняются;
- файлы комментария становятся вложениями задачи; ссылки на них добавляются в конец комментария, если в
  тексте их нет;
- комментарий без текста и файлов не переносится.

## Вложения

Переносятся файлы задачи и её комментариев. Имя файла в выгрузке — `<имя>_<id>.<расширение>`, в Трекере
файл сохраняется с исходным именем.

## Учёт времени

| YouTrack                 | Ворклог                                  |
|--------------------------|------------------------------------------|
| Дата работы              | `start` — полночь этой даты в UTC        |
| Длительность             | `duration` в миллисекундах               |
| На кого записана работа  | `createdBy`                              |
| Дата записи              | `createdAt`                              |
| Тип работы               | Строка «Тип работ: <тип>» в комментарии  |
| Комментарий              | `comment`                                |

Учёт времени выгружается, если он включён в проекте.

## Связи

| Связь YouTrack                    | Связь Трекера                      |
|-----------------------------------|------------------------------------|
| Subtask: parent for               | `is parent task for`               |
| Subtask: subtask of               | `is subtask for`                   |
| Depend: is required for           | `is dependent by`                  |
| Depend: depends on                | `depends on`                       |
| Duplicate: is duplicated by       | `is duplicated by`                 |
| Duplicate: duplicates             | `duplicates`                       |
| Relates и остальные типы          | `relates`                          |

- Связь переносится, если обе задачи в выгрузке. Импорт создаёт обратную связь сам, поэтому связь пары
  записывается один раз — у задачи с меньшим ключом.
- Дата и автор связи берутся из истории задачи. Если в истории их нет — дата создания более поздней из
  двух задач и автор задачи с меньшим ключом.
- Между двумя задачами в Трекере одна связь: из нескольких связей пары переносится первая.
