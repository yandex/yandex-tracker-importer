# Проекты, портфели, доски и статусы

## Проект

Проект WEEEK становится очередью и проектом Трекера. Ключ очереди задаётся в `configs/projects.cfg`.

| WEEEK                 | Yandex Tracker                                   |
|-----------------------|--------------------------------------------------|
| Название              | Название очереди и проекта                       |
| Описание              | Описание очереди и проекта                       |
| Портфель              | «Входит в портфель» (`parentEntity`)             |
| Доски                 | Доски очереди                                    |
| Колонки досок         | Статусы рабочего процесса очереди                |
| Пользовательские поля | Локальные поля очереди                           |

API WEEEK не отдаёт автора и время создания проекта. Поэтому:

- автор проекта и руководитель очереди — владелец токена;
- время создания проекта — время создания его самой ранней задачи;
- у проекта без задач время создания — время экспорта.

Архивный проект не выгружается: восстановите его из архива перед экспортом.

### Доступ

| Проект WEEEK                    | Очередь и проект Трекера                                              |
|---------------------------------|-----------------------------------------------------------------------|
| Открыт всему пространству       | Доступ по умолчанию                                                   |
| В приватном портфеле            | Доступ только у участников проекта и владельца токена                 |
| Приватный                       | Доступ только у участников проекта и владельца токена                 |

Права участников приватного проекта:

- очередь: чтение (`read`), создание (`create`) и изменение (`write`) задач;
- проект: чтение (`READ`) и изменение (`WRITE`).

Команда в доступе к проекту переносится своими участниками: API WEEEK отдаёт участников команды, но не
саму команду. Участник проекта, которого нет среди участников пространства и в `configs/users.cfg`, не
получает прав.

## Портфель

Выгружаются портфели выгружаемых проектов и все их родительские портфели. Вложенность сохраняется.
Автор портфеля — владелец токена, время создания — самое раннее время создания его проектов.

Приватный портфель доступен только владельцу токена: чтение (`READ`) и изменение (`WRITE`). Вложенные
портфели и проекты приватного портфеля тоже переносятся приватными: в WEEEK они наследуют его закрытость.
Если портфели не загрузились или портфель проекта не найден, проект переносится приватным, а ошибка
попадает в сводку. API WEEEK не
отдаёт участников портфеля. Остальным пользователям выдайте доступ в Трекере вручную.

## Доски и статусы

Каждая доска проекта становится доской очереди с теми же колонками. Колонка WEEEK становится статусом.

- Первая колонка доски — начальный статус, остальные — статусы «в работе».
- Колонки с одинаковым названием — один статус. Регистр и лишние пробелы не учитываются. Такие колонки одной
  доски становятся одной колонкой доски Трекера — первой из них.
- Названия длиннее 50 символов обрезаются. Если обрезанные названия совпадают, к ним добавляется « (2)»,
  « (3)».
- Последний шаг рабочего процесса — статус «Решён» (`resolved`).
- Колонка с названием «Открыт», «Решён», «Open» или «Resolved» становится статусом с « (2)» в названии.

Начальный статус очереди — статус первой колонки первой доски. Исключение — очередь со статусом
«Открыт» (см. ниже).

### Задачи вне колонок

В WEEEK задача может не лежать ни на одной доске проекта, например подзадача. Для таких задач:

- незавершённая задача получает статус «Открыт» (`open`), и он становится начальным статусом очереди;
- завершённая задача получает статус «Решён» (`resolved`).

Очередь проекта без досок получает начальный статус «Открыт».

### Правило добавления

Если доска в проекте одна, у неё есть правило добавления по очереди: на доску попадают все задачи очереди.
Если досок несколько, правила добавления нет: на доске задачи из её колонок.

## Пользовательские поля

Локальными полями очереди становятся поля проекта и поля, заполненные хотя бы в одной задаче проекта. Поля
пространства, которые в проекте не заполнены, не переносятся.
Поля с одинаковым названием становятся разными полями: занятое название получает « (2)», « (3)».

| Тип поля в API WEEEK | Локальное поле Трекера                | Значение                              |
|----------------------|---------------------------------------|---------------------------------------|
| `text`               | Многострочный текст                   | Текст                                 |
| `number`             | Дробное число                         | Число                                 |
| `datetime`           | Дата/время                            | Дата и время                          |
| `link`               | Ссылка                                | Адрес                                 |
| `select`             | Список строк                          | Название варианта                     |
| `multiselect`        | Список строк с выбором нескольких     | Названия вариантов                    |
| `boolean`            | Список строк из одного значения «Да»  | «Да», если флажок отмечен             |
| `member`             | Пользователи                          | E-mail участников                     |
| `approval`           | Пользователи                          | E-mail согласующих                    |
| `contact`            | Строка                                | Имена контактов CRM через запятую     |
