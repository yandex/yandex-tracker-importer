# Задачи

Задача WEEEK становится задачей Трекера в очереди своего проекта.

## Поля задачи

| WEEEK                 | Yandex Tracker            | Как переносится                                                   |
|-----------------------|---------------------------|-------------------------------------------------------------------|
| Название              | `summary`                 | Как есть                                                          |
| Автор, время создания | `createdBy`, `createdAt`  | Как есть                                                          |
| Время изменения       | `updatedAt`, `updatedBy`  | Самое позднее из времени изменения и завершения задачи, её комментариев, загрузки файлов и создания подзадач; автор изменения — автор задачи |
| Колонка               | `status`                  | Статус колонки (см. [projects.md](projects.md))                   |
| Тип                   | `type`                    | Задача — `task`, встреча — `meeting`, звонок — `call`             |
| Приоритет             | `priority`                | Низкий — `minor`, средний — `normal`, высокий — `critical`        |
| Приоритет Hold        | `priority`, `tags`        | `normal` и метка `Hold`                                           |
| Исполнители           | `assignee`, `followers`, `access` | Первый исполнитель — `assignee`, остальные — наблюдатели; у приватной задачи — ещё и поле «Доступ» |
| Наблюдатели           | `followers`               | Как есть                                                          |
| Метки                 | `tags`                    | Названия меток                                                    |
| Дата начала           | `start`                   | День                                                              |
| Срок                  | `deadline`                | День                                                              |
| Оценка времени        | `originalEstimation`      | Минуты переводятся в миллисекунды                                 |
| Подзадачи             | `links`                   | Связь «родительская задача — подзадача»                           |
| Пользовательские поля | `local_<ключ>`            | См. [projects.md](projects.md)                                    |

Дата со временем переносится днём в часовом поясе владельца токена (настройки профиля WEEEK).

## Приватные задачи

Приватную задачу WEEEK видят только её автор и исполнители. В Трекере:

- в очереди появляется компонент «Приватные задачи», задачи с ним видят и изменяют автор, исполнитель,
  пользователи из поля «Доступ» и руководитель очереди;
- приватная задача получает этот компонент;
- исполнители после первого попадают в поле «Доступ»;
- подписчики становятся наблюдателями без доступа к задаче, как в WEEEK.

Ставить компонент «Приватные задачи» на задачи может руководитель очереди (владелец токена WEEEK).

Повторный импорт создаёт приватные задачи, если учётная запись импорта — руководитель очереди или указана в
правах компонента на создание, чтение и изменение.

## Завершённые задачи

Завершённая задача получает резолюцию «Решён» (`fixed`).

- Статус остаётся статусом её колонки. Задача вне колонок получает статус «Решён».
- Время решения — время завершения в WEEEK, а без него — время изменения задачи; не раньше создания задачи.
- Автор решения — первый исполнитель с известным e-mail. Если таких исполнителей нет — автор задачи.

## Задача в нескольких проектах

В WEEEK задача может лежать в нескольких проектах. В Трекере у задачи одна очередь.

- Очередь — первый из проектов задачи в WEEEK, который есть в выгрузке.
- Остальные проекты задачи из выгрузки становятся дополнительными проектами (`project.secondary`).
- Доска и колонка берутся из проекта очереди.

## Описание

Описание переводится из HTML в markdown: абзацы, заголовки, выделение, ссылки, списки, блоки кода,
цитаты и таблицы.

- Чек-лист описания становится списком с отметками: `- [x] сделано`, `- [ ] не сделано`.
- Картинка из файлов задачи показывается в тексте ссылкой на вложение.
- Файлы из внешних хранилищ перечисляются ссылками в конце описания под заголовком «Файлы по ссылкам:».
- Упоминание пользователя переносится текстом, как WEEEK отдаёт его: `@Имя Фамилия`.

## Комментарии

Комментарии переносятся с автором и временем. Ответы на комментарии переносятся обычными комментариями.

- Эмодзи из набора WEEEK заменяются похожими эмодзи Unicode. Эмодзи без похожего — его названием,
  например `:sobaka:`.
- Упоминание пользователя переносится текстом.
- Комментарий без текста и без файлов не переносится.

### Файлы комментариев

WEEEK отдаёт файлы комментария среди файлов задачи, без связи с комментарием. Экспорт относит файл к
комментарию, если:

- файл загрузил автор комментария;
- комментарий отправлен в течение минуты после загрузки файла;
- на файл нет ссылки в описании и комментариях.

Такой файл становится вложением задачи. В конце текста комментария появляется ссылка на него, картинка
показывается в тексте. Остальные файлы остаются вложениями задачи без ссылок.

## Файлы

Файлы, загруженные в WEEEK, скачиваются в каталог `attachments/` задачи. Имя файла дополняется его id:
`report.pdf` → `report_<id>.pdf`. В Трекере вложение получает исходное имя.

## Учёт времени

Запись учёта времени становится записью о затраченном времени (`worklogs`).

- Начало — полночь дня записи в часовом поясе владельца токена.
- Время создания — начало записи, но не раньше создания задачи.
- Запись без длительности не переносится.
- Длительность — как есть.
- Комментарий — как есть. В комментарии сверхурочной записи есть строка «Сверхурочно».
