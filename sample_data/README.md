# Пример данных для импорта

В данной директории содержится пример данных для импорта, включащий:
- 1 очередь с ключом `EXAMPLE`
- 5 задач
- 1 проект
- 1 цель
- 1 портфель

В очереди также присутствует триггер и компонент.

В задачах есть примеры чек-листов, комментариев, вложений и заполнены некоторые поля.

Для успешного импорта требуется настроить сопоставления для 2 встречающихся пользователей. Например, для сопоставления с роботом Трекера:

```users.cfg
Иван Иванов:yndx-tracker-cnt-robot
Петр Петров:yndx-tracker-cnt-robot
```
