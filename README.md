# Универсальный импортер для Yandex Tracker

Импортер позволяет загружать данные в Yandex Tracker из YAML-файлов с заданной структурой. Поддерживает маппинг полей, пользователей и логирование операций.

## Основные возможности

* Импорт задач и других сущностей Tracker из YAML
* Гибкий маппинг полей
* Маппинг пользователей (автор, исполнитель)
* Логирование операций в локальную директорию `logs`

## Быстрый старт

### 1. Соберите Docker/Podman образ

**Docker:**

```bash
docker build -t yandex-tracker-importer:latest .
```

**Podman:**

```bash
podman build -t yandex-tracker-importer:latest .
```

### 2. Подготовьте рабочую директорию

Список файлов конфигурации и входных данных описан в [`docs/index.md`](docs/index.md).

Рабочая директория должна содержать:

```
config.yaml
data/
mapping/
logs/     ← будет создан автоматически, если его нет
```

### 3. Запустите импортер

Импортер работает в контейнере и использует примонтированную рабочую директорию `/work`. Далее приведён пример команды запуска импортера из каталога, где находятся входные данные.

**Docker:**

```bash
docker run --rm \
  -v "$(pwd)":/work \
  -w /work \
  yandex-tracker-importer:latest
```

**Podman:**

```bash
podman run --rm \
  --userns=keep-id \
  -v "$(pwd)":/work \
  -w /work \
  yandex-tracker-importer:latest
```

После выполнения логи появятся в директории `logs`.
