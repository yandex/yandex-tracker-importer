# Типы задач

**Файл для импорта:** `statuses.yaml`  
**Расположение:** `./data/statuses.yaml`

> Примечание: Поля, отмеченные звёздочкой (<span style="color: red;">*</span>), являются обязательными.

## Общие сведения

| Поле                                     | Тип    | Описание                        |
|------------------------------------------|--------|---------------------------------|
| `key`<span style="color: red;">*</span>  | Строка | Уникальный ключ статуса         |
| `name`<span style="color: red;">*</span> | Объект | Название статуса на двух языках |
| `type`<span style="color: red;">*</span> | Строка | Тип статуса. Может принимать одно из следующих значений: <br>`new` — Начальный; <br>`inProgress` — В процессе; <br>`paused` — На паузе; <br>`done` — Завершен; <br>`cancelled` — Отменен. |
| `description`                            | Строка | Описание статуса                |

---

## Пример `statuses.yaml`

```yaml
- key: demonstrationToTheCustomer
  name: 
    ru: Демонстрация заказчику
    en: Demonstration to the customer
  type: imProgress
  description: Demonstration to the customer
- key: payment
  name:
    ru: Оплата
    en: Payment
  type: paused
```


## Особенности работы

Статус ищется в целевой организации по ключу. Если по ключу его нет, а в `mapping/statuses.cfg` нет строки для этого ключа, импорт ищет статус с тем же названием на русском или на английском и использует его: создать статус с занятым названием нельзя. В журнале появляется `Status … is mapped to the existing … by the same name`. Названия статусов сравниваются на каждом языке отдельно, без учёта регистра и лишних пробелов. Если название совпадает с названиями нескольких объектов, сопоставление нужно указать в `mapping/statuses.cfg`.

Если тип найденного статуса отличается от типа в выгрузке, в журнале появляется предупреждение.

Если несколько статусов выгрузки сопоставлены с одним статусом, их шаги в воркфлоу объединяются в один: переходы складываются, переход в статус и функции после комментария берутся у первого шага, у которого они есть. В журнале — `Workflow steps of status … are merged into one`.
