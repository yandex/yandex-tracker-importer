# Категории полей

**Файл для импорта:** `categories.yaml`  
**Расположение:** `./data/categories.yaml`

> Примечание: Поля, отмеченные звёздочкой (<span style="color: red;">*</span>), являются обязательными.

## Общие сведения

| Поле                                      | Тип    | Описание                                |
|-------------------------------------------|--------|-----------------------------------------|
| `name`<span style="color: red;">*</span>  | Объект | Название категории полей на двух языках |
| `order`<span style="color: red;">*</span> | Число  | Вес категории полей при отображении в интерфейсе. Поля с меньшим весом отображаются выше полей с большим весом. |
| `description`                             | Строка | Описание категории полей                |

---

## Пример `categories.yaml`

```yaml
- name:
    en: Products
    ru: Товары
  description: Информация о товарах
  order: 100
```
