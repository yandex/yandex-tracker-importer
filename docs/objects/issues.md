# Задачи

**Файл для импорта:** `issue.yaml`  
**Расположение:** `./data/queues/<queue_key>/<issue_key>/issue.yaml`

> Примечание: Поля, отмеченные звёздочкой (<span style="color: red;">*</span>), являются обязательными.

## Общие сведения

| Поле                                          | Тип            | Описание                                                                     |
|-----------------------------------------------|----------------|------------------------------------------------------------------------------|
| `key`<span style="color: red;">*</span>       | Строка         | Ключ задачи (формат: `<queue_key>-<issue_key>`)                              |
| `summary`<span style="color: red;">*</span>   | Строка         | Название задачи (не более 256 символов)                                      |
| `createdAt`<span style="color: red;">*</span> | Строка         | Дата и время создания задачи (формат: `YYYY-MM-DDThh:mm:ss.sss±hhmm`)        |
| `createdBy`<span style="color: red;">*</span> | Строка         | Логин автора задачи                                                          |
| `updatedAt`                                   | Строка         | Дата и время последнего изменения (формат: `YYYY-MM-DDThh:mm:ss.sss±hhmm`)   |
| `updatedBy`                                   | Строка         | Логин пользователя, который последним редактировал задачу                    |
| `resolvedAt`                                  | Строка         | Дата и время проставления резолюции (формат: `YYYY-MM-DDThh:mm:ss.sss±hhmm`) |
| `resolvedBy`                                  | Строка         | Логин пользователя, который поставил резолюцию                               |
| `status`                                      | Строка         | Ключ статуса задачи                                                          |
| `deadline`                                    | Строка         | Дедлайн задачи (формат: `YYYY-MM-DD`)                                        |
| `resolution`                                  | Строка         | Ключ резолюции задачи                                                        |
| `type`                                        | Строка         | Ключ типа задачи                                                             |
| `description`                                 | Строка         | Описание задачи (не более 5120000 символов)                                  |
| `start`                                       | Строка         | Дата начала работы (формат: `YYYY-MM-DD`)                                    |
| `end`                                         | Строка         | Дата окончания работы (формат: `YYYY-MM-DD`)                                 |
| `assignee`                                    | Строка         | Логин исполнителя задачи                                                     |
| `priority`                                    | Строка         | Ключ приоритета задачи                                                       |
| `project`                                     | Строка         | `id` проекта, к которому относится задача                                    |
| `affectedVersions`                            | Массив         | Идентификаторы версий, перечисленные в поле **Найдено в версиях**            |
| `fixVersions`                                 | Массив         | Идентификаторы версий, перечисленные в поле **Исправить в версиях**          |
| `components`                                  | Массив         | Названия компонентов, к которым относится задача                             |
| `tags`                                        | Массив         | Теги задачи                                                                  |
| `followers`                                   | Массив         | Логины наблюдателей задачи                                                   |
| `access`                                      | Массив         | Логины пользователей, перечисленных в поле **Доступ**                        |
| `unique`                                      | Строка         | Уникальный идентификатор задачи                                              |
| `followingMaillists`                          | Массив         | Идентификаторы рассылок — команд и отделов, подписанных на задачу            |
| `originalEstimation`                          | Число          | Первоначальная оценка в миллисекундах                                        |
| `estimation`                                  | Число          | Оценка в миллисекундах                                                       |
| `spent`                                       | Число          | Затрачено времени в миллисекундах                                            |
| `storyPoints`                                 | Число          | Значение параметра Story Points                                              |
| `votedBy`                                     | Массив         | Логины пользователей, которые проголосовали за задачу                        |
| `favoritedBy`                                 | Массив         | Логины пользователей, которые добавили задачу в избранное                    |
| `checklistItems`                              | Массив объектов| Чеклисты в задаче                                                            |
| `comments`                                    | Массив объектов| Комментарии к задаче                                                         |
| `attachments`                                 | Массив объектов| Вложения к задаче                                                            |
| `worklogs`                                    | Массив объектов| Ворклоги задачи                                                              |
| `links`                                       | Массив объектов| Связи между задачами                                                         |
| `local_<название поля>`                       | Строка, число  | Локальное поле задачи (может быть несколько)                                 |

## Структура `checklistItems`

| Поле                                     | Тип        | Описание                                         |
|------------------------------------------|------------|--------------------------------------------------|
| `text`<span style="color: red;">*</span> | Строка     | Текст пункта чеклиста                            |
| `checked`                                | Логическое | Отметка о выполнении пункта                      |
| `assignee`                               | Строка     | Логин исполнителя пункта чеклиста                |
| `deadline`                               | Строка     | Дедлайн (формат: `YYYY-MM-DDThh:mm:ss.sss+hhmm`) |

## Структура `comments`

| Поле                                          | Тип    | Описание                                                             |
|-----------------------------------------------|--------|----------------------------------------------------------------------|
| `text`<span style="color: red;">*</span>      | Строка | Текст комментария                                                    |
| `createdAt`<span style="color: red;">*</span> | Строка | Дата создания комментария (формат: `YYYY-MM-DDThh:mm:ss.sss+hhmm`)   |
| `createdBy`<span style="color: red;">*</span> | Строка | Логин пользователя, создавшего комментарий                           |
| `updatedAt`                                   | Строка | Дата обновления комментария (формат: `YYYY-MM-DDThh:mm:ss.sss+hhmm`) |
| `updatedBy`                                   | Строка | Логин пользователя, обновившего комментарий                          |

## Структура `attachments`

| Поле                                          | Тип    | Описание                                                        |
|-----------------------------------------------|--------|-----------------------------------------------------------------|
| `filename`<span style="color: red;">*</span>  | Строка | Название файла в директории                                     |
| `createdAt`<span style="color: red;">*</span> | Строка | Дата создания вложения (формат: `YYYY-MM-DDThh:mm:ss.sss+hhmm`) |
| `createdBy`<span style="color: red;">*</span> | Строка | Логин пользователя, создавшего вложение                         |
| `name`                                        | Строка | Имя файла, с которым он будет храниться на сервере. Если параметр не указан, будет использовано собственное имя файла |

## Структура `worklogs`

| Поле                                           | Тип     | Описание                                                      |
|------------------------------------------------|---------|---------------------------------------------------------------|

| `duration`<span style="color: red;">*</span>   | Число   | Продолжительность ворклога в миллисекундах                    |
| `comment`                                      | Строка  | Комментарий к ворклогу                                        |

## Структура `links`

| Поле                                             | Тип    | Описание                                                       |
|--------------------------------------------------|--------|----------------------------------------------------------------|
| `issue`<span style="color: red;">*</span>        | Строка | Ключ связываемой задачи                                        |
| `relationship`<span style="color: red;">*</span> | Строка | Тип связи между задачами. Может принимать одно сз следующих значений: <br>`relates` — простая связь; <br>`is dependent by` — текущая задача является блокером; <br>`depends on` — текущая задача зависит от связываемой; <br>`is subtask for`  — текущая задача является подзадачей связываемой; <br>`is parent task for` — текущая задача является родительской для связываемой задачи; <br>`duplicates` — текущая задача дублирует связываемую; <br>`is duplicated by` — связываемая задача дублирует текущую; <br>`is epic of` — текущая задача является эпиком связываемой. Связь такого типа можно установить только для задач типа "Эпик"; <br>`has epic` — связываемая задача является эпиком текущей. Связь такого типа можно установить только для задач типа "Эпик".|
| `createdAt`<span style="color: red;">*</span>    | Строка | Дата создания связи (формат: `YYYY-MM-DDThh:mm:ss.sss+hhmm`)   |
| `createdBy`<span style="color: red;">*</span>    | Строка | Логин пользователя, создавшего связь                           |
| `updatedAt`                                      | Строка | Дата обновления связи (формат: `YYYY-MM-DDThh:mm:ss.sss+hhmm`) |
| `updatedBy`                                      | Строка | Логин пользователя, обновившего связь                          |

## Пример `issue.yaml`

```yaml
key: QUEUE-1
summary: Test Issue
createdAt: "2025-02-08T17:00:00.000+0300"
status: new
description: Issue description
createdBy: login1
assignee: login2
priority: normal
type: task
followers:
  - login3
components:
  - "First_component"
  - "Second component"
tags:
  - test
checklistItems:
  - text: Check frontend
    checked: true
    assignee: login3
    deadline: "2025-04-15T10:00:00.000+0300"
comments:
  - text: Issue comment
    createdAt: "2025-03-18T10:10:00.000+0300"
    createdBy: login2
    updatedAt: "2025-04-10T10:30:00.000+0300"
    updatedBy: login2
attachments:
  - name: attachment.txt
    createdAt: "2025-04-10T10:30:00.000+0300"
    createdBy: login2
worklogs:
  - start: "2025-04-10T10:30:00.000+0300"
    duration: 3600
    comment: Worklog comment
links:
  - issue: QUEUE-2
    relationship: relates
    createdAt: "2025-03-18T10:10:00.000+0300"
    createdBy: login2
    updatedAt: "2025-04-10T10:30:00.000+0300"
    updatedBy: login2
project: projectId
```

## Особенности работы

1. **Некорректные даты**: В случае задания даты обновления раньше даты создания, дата обновления будет приведена к дате создания.
2. **Вложения**: Все вложения, указанные в данных, должны находиться в директории `attachments` внутри директории задачи.
